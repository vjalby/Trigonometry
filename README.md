Version 1.4 [2026/10/10]  
© 2004-2026, Vincent Jalby. Licensed under the GNU General Public License, version 3.

Trigonometry is a small application to help you learn (or teach) trigonometry and specifically sinus and cosinus.

## System Requirements

Trigonometry requires macOS 13 or later (Apple silicon or Intel).

## Installation

Drag Trigonometry to your Applications folder.

The first time you open it, macOS may block the application because it is not notarized by Apple. In that case, open System Settings > Privacy & Security, scroll down to the Security section and click “Open Anyway”.

## Using Trigonometry

- Drag the red dot along the circle to display the angle, sinus and cosinus values.
- When you stop dragging the red dot, sinus and cosinus coordinates are displayed.
- When you drag the red dot clockwise, starting from (1, 0), the dot and angle turn to blue, meaning you're using the negative orientation. Click on (1, 0) to restore default (positive) orientation.
